# ⚽ FIFA 23 | Player & Club Analytics

## 📊 Project Overview

An interactive **Power BI dashboard** analysing 18,539 FIFA 23 players to explore player ratings, market values, wages, demographics, and club performance.

The project demonstrates how football data can be transformed into actionable insights through data modelling, DAX, and interactive visualisations.

## 🎯 Key Analysis Areas

- **Player Performance:** Top-rated players and average player ratings.
- **Club Analysis:** Top 10 clubs ranked by average player rating.
- **Market Value:** Relationship between player age and market value.
- **Wage Analysis:** Relationship between player wages and overall ratings.
- **Player Demographics:** Distribution by position and nationality.

## 🛠️ Tools & Technologies

- **Power BI Desktop** — Dashboard development and visualisation
- **Power Query** — Data cleaning and transformation
- **DAX** — Calculated measures and aggregations
- **Data Modelling** — Data relationships and organisation

## ✨ Dashboard Features

- Interactive slicers for nationality, position, and contract year
- KPI cards and comparative visualisations
- Player-level drillthrough for detailed analysis
- Club-level drillthrough for squad analysis
- Interactive charts and cross-filtering

## 📂 Dataset

**Source:** [FIFA 23 Players Dataset — Kaggle](https://www.kaggle.com/datasets/sanjeetsinghnaik/fifa-23-players-dataset)

## 💡 Skills Demonstrated

Data Cleaning · Data Modelling · DAX · Data Visualisation · Drillthrough · Interactive Reporting · Business Intelligence

## 📌 Project Outcome

Developed a three-page Power BI report comprising one analytical overview and two dedicated drillthrough pages, enabling users to explore player performance, compare clubs, and investigate football market trends.
